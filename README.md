# Rupeevalcore Financial Education Website

**Premium educational platform for finance workshops**

This repository contains the source code for the Rupeevalcore website, a comprehensive platform offering financial literacy workshops, NISM certification courses, and personal finance guidance.

**Live URL**: [https://www.rupeevalcore.in](https://www.rupeevalcore.in)

## Features

- **Workshop Curriculum**: Detailed breakdown of 6 learning modules.
- **Premium Chatbot**: Custom animated chatbot (RupeeBot) with Google Sheets integration for lead capture.
- **Responsive Design**: Mobile-first approach optimized for all devices.
- **Interactive Elements**: 3D hover effects, scroll animations, and dynamic counters.
- **Verification**: Display of NISM Series-XII certification.
- **Testimonials**: Carousel of student feedback.

## Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS (CDN)
- **Icons**: Iconify
- **Animations**: CSS3, Vanilla-tilt.js, Intersection Observer
- **Backend**: Google Apps Script (for Chatbot)
- **Database**: Google Sheets
