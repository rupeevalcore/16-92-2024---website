**Step 1: Identify What to Change**
```
Example changes:

- Change workshop pricing
- Add new workshop topic
- Update team member info

**Step 2: Request Update from AI**
```

"I want to update the phone number to +91 XXXXX XXXXX"
"Please add a new workshop topic: Cryptocurrency Basics"
"Change the Group Session price to ₹599"

**Step 3: AI Makes Changes**

**Step 4: Verify Changes**
- Wait 1-2 minutes
- Visit www.rupeevalcore.in

- Clear browser cache if needed (Ctrl + Shift + R)

## 11. Performance Optimizations

### Implemented Optimizations

#### 1. Resource Loading Strategy

**Critical Resources (Load Immediately):**
```html
<!-- Preconnect to external domains -->
<link rel="preconnect" href="https://cdn.tailwindcss.com">
<link rel="preconnect" href="https://cdn.jsdelivr.net">
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- DNS prefetch for less critical domains -->
<link rel="dns-prefetch" href="https://script.google.com">

<!-- Preload critical image -->
<link rel="preload" as="image" href="/logo.jpg" fetchpriority="high">
```

**Non-Critical Resources (Deferred):**
```html
<!-- Defer JavaScript that's not needed immediately -->
<script defer src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/iconify-icon@1.0.7/dist/iconify-icon.min.js"></script>
```

**Performance impact:**
- Faster First Contentful Paint (FCP)
- Improved Largest Contentful Paint (LCP)
- Better Time to Interactive (TTI)

---

#### 2. Font Optimization

**Before (Slow):**
```html
<link href="fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600">
```

**After (Optimized):**
```html
<link href="fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600&display=swap" rel="stylesheet">
```

**What `display=swap` does:**
- Shows fallback font immediately
- Swaps to Inter when loaded
- Prevents "flash of invisible text" (FOIT)
- Ensures text always visible

---

#### 3. Image Optimization

**Current:**
```html
<img src="/logo.jpg" alt="..." width="48" height="48" fetchpriority="high">
```

**Optimizations applied:**
- Explicit width/height (prevents layout shift)
- fetchpriority="high" (prioritize hero image)
- Alt text (accessibility + SEO)

**Future improvements:**
- Convert to WebP format (smaller file size)
- Use responsive images (srcset)
- Lazy load below-fold images

---

#### 4. CSS Strategy

**Inline Critical CSS:**
```html
<style>
  /* All styles inline in <head> */
  /* Avoids render-blocking external CSS */
  /* Faster First Paint */
</style>
```

**Tailwind via CDN:**
```html
<script src="https://cdn.tailwindcss.com"></script>
```

**Trade-off:**
- Pro: No build step needed, fast development
- Con: Larger file size (entire Tailwind library)
- Mitigation: Vercel GZIP compression

**Production alternative:**
Use Tailwind CLI to generate only used classes:
```bash
npx tailwindcss -i input.css -o output.css --minify
# Reduces file size by ~95%
```

---

#### 5. JavaScript Optimization

**Pattern: Minimal blocking scripts**
```html
<!-- Only critical JS inline -->
<script>
  tailwind.config = { /* small config */ };
  emailjs.init("key"); // Small init
</script>

<!-- All other JS deferred or at end of body -->
```

**Code efficiency:**
- Vanilla JS (no jQuery ~80KB saved)
- ES6 features (modern, efficient)
- Event delegation (fewer listeners)

---

#### 6. Animation Performance

**CSS transforms (GPU-accelerated):**
```css
.card-3d {
  transform: rotateX(8deg) rotateY(-4deg);  /* Uses GPU */
  transition: transform 0.4s ease;           /* Smooth */
}
```

**Not CPU-intensive properties:**
```css
/* GOOD (GPU) */
transform: translateX(...);
opacity: 0.5;

/* BAD (CPU, causes reflow) */
left: 100px;
width: 50%;
```

---

#### 7. Scroll Performance

**Intersection Observer (modern approach):**
```javascript
// Better than scroll event listener
const revealOnScroll = () => {
  const windowHeight = window.innerHeight;
  revealElements.forEach(reveal => {
    // Only check elements, no constant calculation
  });
};
window.addEventListener("scroll", revealOnScroll);
```

**Passive event listeners** (if needed):
```javascript
window.addEventListener("scroll", handler, { passive: true });
// Allows browser to optimize scrolling
```
