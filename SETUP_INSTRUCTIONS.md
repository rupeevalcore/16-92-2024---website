# 🚀 Rupeevalcore Website - Complete Setup Guide

## Step 1: Install Node.js (Required)

### Download & Install:
1. **Visit**: https://nodejs.org/
2. **Download**: "LTS" version (recommended) - currently v20.x or v22.x
3. **Run installer**: Follow default options
4. **Verify installation**: Open PowerShell and run:
   ```bash
   node --version
   npm --version
   ```
   You should see version numbers if installed correctly.

---

## Step 2: Install Project Dependencies

Once Node.js is installed:

```bash
cd D:\rupeevalcoreproject
npm install
```

This will install:
- Vite (build tool)
- Tailwind CSS (optimized CSS framework)
- PostCSS & Autoprefixer (CSS processing)

**Expected time**: 1-2 minutes

---

## Step 3: Run Development Server

```bash
npm run dev
```

This will:
- Start a local server at http://localhost:3000
- Auto-reload when you make changes
- Show you the optimized version in real-time

---

## Step 4: Build for Production

When ready to deploy:

```bash
npm run build
```

This creates an optimized `dist/` folder with:
- Minified HTML, CSS, JS
- Optimized assets
- Production-ready files
