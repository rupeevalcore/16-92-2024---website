## 🐛 TROUBLESHOOTING GUIDE

### Issue: Website not updating after push
**Solution:**
1. Check Vercel dashboard for deployment status
2. Wait 1-2 minutes for deployment to complete
3. Clear browser cache (Ctrl + Shift + R)
4. Check in incognito mode

### Issue: Domain shows error
**Solution:**
1. Check DNS settings in GoDaddy
2. Verify A record = 76.76.21.21
3. Verify CNAME = vercel-dns.com
4. Wait 10-30 minutes for DNS propagation

### Issue: Git push fails
**Solution:**
```bash
git pull origin main --rebase
git push origin main
```

### Issue: Need to revert changes
**Solution:**
```bash
git log                    # See commit history
git revert [commit-hash]   # Revert specific commit
git push origin main       # Push revert
```
